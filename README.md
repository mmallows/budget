# Budget
A personal budgeting app using Java, Maven - soon to be JavaFX and Hibernate ORM

# Features
Currently, the only feature is that you can import a csv file matching the format of TD Bank's CSV download and tell you the general total debits and credits.
That might not even work currently, but hopefully it will soon.

# Vision
Other budgeting apps like Rocketmoney or NerdWallet don't really give me the information I want in terms of whether I'm making my budget month-to-month.
My vision for this app is that I'll be able to construct a budget for each month or period and I'll be able to get information from the history of transactions in the db such as:
- How much did I spend on groceries this month?
- How much did I budget for groceries for this month?
- How does my spending compare this month versus last month?
- Over the past 6 months, how accurate were my budgets? What kind of unexpected expenses came up?
There are a few other features I'd like to add which are sometimes only available in the Premium tiers of other budgeting apps:
- Automatically sorting transactions into their corresponding bucket based on historical data
- Possibly sorting the select dropdown by frequency (most used buckets first, least used last)
- Custom budget month to month - Maybe my budget changes 6 months through the year and I want that history so that I'm not judging my whole year off a budget I only had for 3-6 months
